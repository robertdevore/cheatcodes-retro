# CheatCodes.com 2001 recreation

Build: `kujo run build.kujo -- --no-webmcp`

Kujo SSG 1.2.0 generates dist from templates and assets. SiteKit 1.1.0 is vendored in assets/sitekit with its licenses. The user-provided reference is used as a CSS sprite sheet for original chrome and illustrations; news copy is live HTML. The fixed 830×790 reference canvas scales on smaller screens. Historical account services, giveaways and game databases are not connected; interactions disclose this explicitly.
