## Fonts

- [Gruppo](https://fonts.google.com/specimen/Gruppo), by Vernon Adams: thin masthead and footer lettering.
- [Michroma](https://fonts.google.com/specimen/Michroma), by Vernon Adams: extended technical headings.

Both were obtained through Google Fonts, subset to printable ASCII, and self-hosted as WOFF2. Their SIL Open Font Licenses are in `assets/fonts/`. They are visual matches for the reference's style; the original 2001 typefaces have not been identified. Body text stays Arial and navigation stays monospace.

Chrome frames, bevels, gradients, the masthead emblem, pier scene, and hardware illustrations remain editable CSS and SVG. No screenshot sprites or raster artwork are shipped.
